Папка для расширения конфигурации 1С (.cfe), которое помощник раздаёт сотрудникам.

Положите сюда файл расширения — и всё. Бот начнёт присылать его:
  * вместе с комплектом подключения базы — команда /toolkit;
  * отдельно — команда /расширение.
Перезапускать бота не нужно. Что лежит в папке, видно в панели: «Базы 1С» → «Комплект для сотрудника».

Сотрудник ставит расширение в свою копию базы сам:
Все функции → Стандартные → Управление расширениями конфигурации → «Добавить из файла»
(в конфигурациях на БСП: Администрирование → Печатные формы, отчёты и обработки → Расширения),
затем перезапускает 1С.

Файлы из этой папки в git не попадают (кроме этого README).
