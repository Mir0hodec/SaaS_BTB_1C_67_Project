# MCP_HTTPService 0.5 — с обезличиванием

Основа — расширение MCP_HTTPService 0.4.8 из [feenlace/mcp-1c](https://github.com/feenlace/mcp-1c) (лицензия MIT).
Добавлено: общий модуль `MCP_Обезличивание` (метки вместо конфиденциальных значений в `/query`, `/validate-query`,
`/eventlog`), методы `/anonymization` (привязка моста, правила) и `/detokenize` (расшифровка — только с ключом моста).

- `src/` — XML-выгрузка расширения (формат 8.3.23+, режим совместимости 8.3.14).
- Сборка `.cfe`: `python scripts/build_extension.py` → `extensions/MCP_HTTPService.cfe` (временная база, проверка модулей).
- Проверить на данных без веб-публикации: в базе с расширением —
  `MCP_Обезличивание.ВыполнитьЗапрос("ВЫБРАТЬ ПЕРВЫЕ 5 Наименование ИЗ Справочник.Контрагенты")`.
