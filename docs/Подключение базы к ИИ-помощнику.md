# Подключение своей копии базы 1С к ИИ-помощнику

Помощник (бот в 1С-Коннекте) работает с копией клиентской базы **на вашем компьютере** через обработку **MCP Toolkit**: смотрит метаданные и данные, читает журнал регистрации, разбирает ошибки, может исправлять данные и присылает готовые внешние обработки и отчёты. Веб-публикация (IIS) не нужна, конфигурация базы не меняется.

## Один раз на компьютере

1. **Пароль.** В своей копии базы у пользователя **Администратор** должен быть пароль **1** — не рабочий пароль. Помощник проверяет это сам и с другим паролем работать откажется.
2. **Файлы.** Напишите помощнику `/toolkit` — он пришлёт `MCP_Toolkit.epf`, `MCP_Toolkit_x86.epf` и `employee_toolkit.ps1`. Сохраните их в одну папку.
3. **Настройка.** `employee_toolkit.ps1` → правой кнопкой → «Выполнить с помощью PowerShell» → выберите папку базы. Скрипт откроет порт 6003 **только для сервера помощника** (192.168.0.47) и создаст ярлык «1С + MCP Toolkit (база)».
4. **Запуск.** Откройте базу этим ярлыком (вход под Администратор/1 и запуск MCP Toolkit — автоматически). В окне MCP Toolkit:
   - режим «Встроенный сервер», порт 6003, адрес «Все интерфейсы»;
   - «Токен доступа» → «Сгенерировать»;
   - если помощник должен исправлять данные — включите автоподтверждение **«Записать»**;
   - «Запустить сервер». **Окно не закрывайте** — пока оно открыто, помощник видит базу.
5. **Регистрация.** Передайте администратору помощника адрес из окна скрипта (`http://<ваш IP>:6003/mcp`) и токен. Он добавит базу в панели управления (раздел «Базы 1С»), задаст хэштег и нажмёт «Проверить».

## Работа

Пишите помощнику с хэштегом базы: «#гке почему не проводится документ ПТУ-000123», «#гке покажи первые 10 документов», «сделай обработку загрузки цен из Excel для #гке».

## Если не работает

| Ответ помощника | Что сделать |
|---|---|
| «База сейчас недоступна» | Откройте базу ярлыком и нажмите «Запустить сервер» в MCP Toolkit. Проверьте, что ПК не сменил IP. |
| «Пароль «1» не подходит» | В копии базы задайте Администратору пароль 1, откройте базу заново. |
| «База открыта под пользователем …» | Откройте базу ярлыком «1С + MCP Toolkit» (он входит под Администратором). |
| «Токен не подошёл» | Токен в форме MCP Toolkit сгенерирован заново — передайте новый администратору. |
| «Операция запрещена … Записать» | В окне MCP Toolkit включите автоподтверждение «Записать». |
| Обработка из чата не открывается | 32-разрядной 1С нужен `MCP_Toolkit_x86.epf`; файлы обработок из чата открываются «Файл → Открыть». |

## Безопасность

- Порт открыт только для сервера помощника; токен — у вас и в защищённом хранилище помощника.
- Удаление объектов MCP Toolkit блокирует всегда; помощник ставит пометку удаления.
- Пароль 1 — только для **копии** базы на вашем ПК. Не ставьте его в рабочих базах клиентов.
