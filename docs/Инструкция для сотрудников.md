# ИИ-помощник ГК «Эксперт»: инструкция для сотрудников

Помощник — это бот в 1С-Коннекте. Пишите ему в линию **«ИИ-помощник»**. Он отвечает на вопросы по нашим программам, проверяет контрагентов, работает с базами 1С клиентов и присылает готовые файлы: Excel, Word, внешние обработки и отчёты 1С.

## Что умеет помощник

| Задача | Как попросить |
|---|---|
| Ответить, как что-то сделать в программе | «как начислить пени в ОСИ?», «как загрузить выписку банка» — ищет ответ в базе знаний компании |
| Проверить контрагента | «проверь контрагента 750710450345» — долг и неподписанные ЭАВР |
| Разобраться с данными в базе клиента | «http://сервер/База почему не проводится поступление №15?», дальше — «покажи остатки по складу» |
| Исправить данные в базе | «поставь сахару цену 380 и проведи поступление №15» — только в копии базы на вашем ПК |
| Посмотреть опубликованную базу | «http://сервер/База какие документы есть в конфигурации», «ошибки в журнале регистрации за вчера» — такую базу помощник только читает |
| Сделать обработку или отчёт | «сделай обработку загрузки цен из Excel» — пришлёт файл .epf/.erf |
| Разобрать скриншот или файл | приложите картинку, PDF или Excel к сообщению и напишите, что нужно |

## Как писать

- Откройте в 1С-Коннекте линию **«ИИ-помощник»**. Если её нет в списке, подключите её в разделе линий поддержки: она доступна всем сотрудникам компании, подключение подтверждается сразу.
- Пишите обычным языком, одним сообщением: что случилось и что нужно получить.
- **Базу 1С выбирают ссылкой на неё.** Пришлите адрес базы — можно вместе с вопросом:
  - опубликованная база — адрес из браузера, например `http://сервер/ИмяБазы`;
  - копия базы на вашем компьютере — адрес MCP Toolkit, например `http://192.168.0.51:6003/mcp`.
- Свои базы и ссылки на них — команда `/базы`. Дальше в разговоре ссылку повторять не нужно. Чтобы перейти к другой базе, пришлите ссылку на неё.
- Помощник помнит разговор: «а теперь то же по месяцам в Excel». Через час тишины разговор начинается заново; начать сразу — `/новый`.
- Сначала сразу придёт «Принял, работаю над ответом…», потом ответ. Сложный вопрос помощник обдумывает несколько минут.
- Если бот вам не отвечает совсем — напишите администратору помощника.

Команды:

| Команда | Что делает |
|---|---|
| `/помощь` | короткая подсказка |
| `/базы` | ваши базы 1С и ссылки на них |
| `/новый` | начать разговор заново |
| `/инструкция` | эта инструкция файлом |
| `/toolkit` | файлы для подключения своей копии базы |
| `/расширение` | расширение конфигурации, если администратор его выложил |
| `/id` | ваш идентификатор — нужен администратору |

## Подключить опубликованную базу — ссылкой

Самый простой способ, если база опубликована на веб-сервере (открывается в браузере):

1. Напишите помощнику `/расширение` — он пришлёт `MCP_HTTPService.cfe`.
2. В базе: **Все функции → Стандартные → Управление расширениями конфигурации** → «Добавить из файла» (в конфигурациях на БСП: **Администрирование → Печатные формы, отчёты и обработки → Расширения**). Снимите «Безопасный режим», перезапустите 1С.
3. У пользователя **Администратор** в этой базе должен быть пароль **1**.
4. Пришлите помощнику **ссылку на базу** — адрес из браузера, можно сразу с вопросом: «http://сервер/База расскажи про конфигурацию». Помощник сам проверит расширение, подключит базу и ответит. Дальше спрашивайте без ссылки — он помнит разговор. Чтобы вернуться к этой базе позже, снова пришлите ссылку.

Если помощник ответит «не отвечает HTTP-сервис расширения», значит, в публикации базы не включены HTTP-сервисы расширений. Это делается один раз: Конфигуратор → Администрирование → Публикация на веб-сервере → «Публиковать HTTP сервисы расширений по умолчанию» → «Опубликовать». Если доступа к конфигуратору сервера нет — попросите администратора.

Такую базу помощник только **читает**: состав конфигурации, данные, журнал регистрации, формы. Исправить данные в ней он не может — подскажет, что поправить, или сделает обработку.

## Подключить свою копию базы

Помощник работает с копией клиентской базы **на вашем компьютере** через обработку **MCP Toolkit**. Веб-публикация не нужна, конфигурация базы не меняется. Работают только файловые базы.

### Один раз

1. **Пароль.** В своей копии базы задайте пользователю **Администратор** пароль **1** — не рабочий пароль. Помощник проверяет это сам и с другим пользователем или паролем работать откажется.
2. **Файлы.** Напишите помощнику `/toolkit` — он пришлёт `MCP_Toolkit.epf`, `MCP_Toolkit_x86.epf`, `employee_toolkit.ps1` и эту инструкцию. Сохраните всё в одну папку.
3. **Настройка компьютера.** Нажмите на `employee_toolkit.ps1` правой кнопкой → «Выполнить с помощью PowerShell», подтвердите права администратора и выберите папку базы (ту, где лежит файл `1Cv8.1CD`). Скрипт:
   - открывает порт 6003 **только для сервера помощника**;
   - создаёт на рабочем столе ярлык «1С + MCP Toolkit (имя базы)»;
   - показывает адрес вида `http://192.168.0.51:6003/mcp` — это ссылка на вашу базу.
4. **Первый запуск.** Откройте базу этим ярлыком: вход под «Администратор» и запуск MCP Toolkit произойдут сами. Если 1С спросит про безопасность внешней обработки — разрешите. В окне MCP Toolkit у поля **«Токен доступа»** нажмите **«Сгенерировать»**. Токен сохранится, повторять не нужно.
5. **Регистрация.** Передайте администратору помощника адрес из окна скрипта и токен — лично, не в общем чате. Он внесёт базу в список и проверит подключение. После этого пришлите помощнику адрес базы — можно сразу с вопросом.

### Каждый раз, когда работаете с помощником

1. Откройте базу ярлыком «1С + MCP Toolkit».
2. Если помощник должен **исправлять данные**, прокрутите окно MCP Toolkit вниз и в блоке **«Автоматически разрешать операции»** поставьте галочку **«Записать»**. Галочка не запоминается: ставьте её после каждого открытия базы. Галочку «Разрешать опасные операции с подтверждением» **не включайте** — иначе 1С будет спрашивать вас на каждую такую операцию, а помощник ждать ответа.
3. **Не закрывайте** окно MCP Toolkit и базу, пока ждёте ответа: помощник видит базу, только пока она открыта.

> Помощник работает с базой от имени «Администратор». Удалять объекты MCP Toolkit не даёт никогда: вместо удаления помощник ставит пометку удаления. Перед изменениями он называет базу и что именно меняет, а после — перечисляет, что изменил.

## Готовые обработки и отчёты

- Файл `.epf` или `.erf` приходит в чат. Сохраните его и откройте в базе: **Файл → Открыть**. Если 1С спросит про безопасность — разрешите.
- Обработка собрана на сервере под платформу 8.3.24. Если не открывается — напишите помощнику, какая ошибка, он исправит.
- Сначала проверяйте обработку на копии базы, потом переносите в рабочую.

## Расширение конфигурации

Если администратор выложил расширение, оно придёт вместе с `/toolkit` или по команде `/расширение`. Установка в копию базы:

1. **Все функции → Стандартные → Управление расширениями конфигурации** → «Добавить из файла». В конфигурациях на БСП: **Администрирование → Печатные формы, отчёты и обработки → Расширения**.
2. Выберите файл `.cfe`, при необходимости снимите флажок «Безопасный режим».
3. Перезапустите 1С.

## Если не работает

| Ответ помощника или проблема | Что сделать |
|---|---|
| Помощник не понимает, о какой базе речь | Пришлите ссылку на базу вместе с вопросом. Список своих баз — `/базы`. |
| «Копии базы по адресу … нет в списке помощника» | Передайте этот адрес и токен MCP Toolkit администратору помощника. |
| «База … сейчас недоступна» | Откройте базу ярлыком «1С + MCP Toolkit» и не закрывайте окно MCP Toolkit. Если компьютер получил другой IP-адрес — сообщите новый адрес администратору. |
| «Пароль «1» не подходит» | В базе задайте пользователю Администратор пароль 1 и откройте базу ярлыком заново. |
| «База открыта под пользователем …» | Закройте 1С и откройте базу ярлыком «1С + MCP Toolkit» — он входит под Администратором. |
| «Токен не подошёл» | Токен в окне MCP Toolkit сгенерировали заново. Передайте новый токен администратору. |
| «Операция запрещена … Записать» | Внизу окна MCP Toolkit, в блоке «Автоматически разрешать операции», поставьте галочку «Записать» и повторите просьбу. |
| «База закреплена за другим сотрудником» | Базу подключал коллега. Подключите свою копию или попросите администратора открыть вам доступ. |
| Ярлык не открывает базу | Проверьте, что в копии есть пользователь «Администратор» с паролем 1. Для 32-разрядной 1С нужен `MCP_Toolkit_x86.epf` рядом со скриптом. |
| Бот долго не отвечает | Ответ может идти несколько минут. Если больше 15 минут — напишите администратору помощника. |

## Безопасность

- Пароль **1** ставьте только в **копии** базы на своём компьютере. Никогда — в рабочих базах клиентов.
- Не отправляйте помощнику пароли, ключи и токены. Токен MCP Toolkit передавайте только администратору.
- Порт 6003 на вашем компьютере открыт только для сервера помощника.
- Помощник может ошибаться. Проверяйте важные цифры и изменения в базе, прежде чем переносить их клиенту.
